# 非标产品报价查询

适合手机浏览器的静态查询系统。输入商品编码、图号、产品名称或规格，即可查看最近一次有金额的报价及日期。展开「历史记录」可查看历次报备，包括经销商、材料、货期和数量分档。缺少编码和图号的记录按名称与规格归组。

## 发布到 GitHub Pages

1. 解压项目包，在 GitHub 新建仓库。使用 GitHub Free 个人账号时，选择公开仓库即可启用 Pages。
2. 在仓库的文件上传页面，将解压后的项目内容一起拖入，保留 vendor 文件夹，确认 index.html 位于仓库根目录。将文件提交至 main 分支。
3. 在仓库的 Settings → Pages 中选择 Deploy from a branch，选 main 分支和 / (root) 文件夹，再点 Save。
4. 等待发布完成，打开 Pages 显示的网址。手机可直接通过这个网址使用系统。

[GitHub Pages 发布设置说明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## 手机使用

首次打开网页，点「导入报备表」，选择原始 .xlsx 报备文件，再点「使用这份报备表」。程序读取第一个含有报备明细的工作表，表头需要包含「日期」「商品编码」「产品图号」「产品名称」「产品规格」「报价」。编码、图号和报价的单元格允许留空。

最近一个有报价的日期如果有多笔记录，查询结果会列出当天各笔报价。勾选「只看多期报价」可以筛出在两个或更多日期有过报价的产品。

报备表由浏览器在本机读取并保存。只将项目代码上传到 GitHub。每台设备首次使用时分别导入。要更新，点「更新报备表」并选择含完整历史的新版文件，确认后会替换这台设备里的查询数据。清除浏览器网站数据后需要重新导入。

## 项目文件

index.html 为页面入口，styles.css 管理外观，app.js 处理导入、查询和历史报价。vendor 目录包含 JSZip 及其许可文件。项目可直接作为静态网站发布，无需安装依赖或运行构建命令。
